# LaTeX source

`sparse-settlement.tex` is the typeset form of `../paper-v0.9.md` — the same text, with the bounds as real
mathematics and the tables as `booktabs`. The Markdown draft stays the working copy; this is what gets sent.

```bash
brew install tectonic          # once
tectonic -X compile sparse-settlement.tex --outdir out
```

`fig-region.png` is a copy of the figure in the parent directory, regenerated by `node ../region2.mjs`.
The built PDF is committed one level up as `../sparse-settlement-v0.9.pdf`; `out/` is not.
